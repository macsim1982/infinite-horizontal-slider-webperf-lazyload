Slider PLP performant

Case study Lacoste / Celio — bootstrap minimal, chunk slider lazy, délégation d'événements.

  • Grille PLP : ~30 tuiles dans le HTML initial (simulation SFCC, généré au build)
  • Desktop : init au mouseenter de la tuile (pas au scroll avec curseur)
  • Mobile : init au viewport (IntersectionObserver)
  • Prefetch mobile : téléchargement du chunk au touchstart, sans init (pas de jank)
  • Images placeholder : loading="lazy" + dimensions fixes (CWV / CLS)

Démo DevTools : onglet Network, filtrer JS, recharger — rester sur cette section. Aucun chunk slider ne doit apparaître avant le scroll (desktop) ou le survol d'une tuile. Images hors viewport chargées en lazy ; onglet Performance : pas de layout shift grâce aux attributs width/height.
